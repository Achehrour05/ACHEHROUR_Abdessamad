Welcome to the official digital portfolio of **Abdessamad Achehrour**, Engineering Student in Networks & Information Systems at the Faculty of Sciences and Techniques of Marrakech (FSTG).

---

## 🚀 Key Highlights & Projects

* **VisionGuide AI:** Computer Vision assistance system for the visually impaired utilizing Deep Learning and PyTorch.
* **MaskGuard System:** Real-time face mask and PPE compliance detection engine with YOLOv8.
* **Medical Dialogue SOAP Generator:** Clinical NLP summarizer generating structured SOAP notes from doctor-patient dialogues.
* **FPL Squad Optimizer:** Algorithmic team optimization engine leveraging linear programming.
* **MovieCluster:** Unsupervised clustering and recommendation system powered by K-Means and Scikit-Learn.

---

## 🛠️ Tech Stack & Arsenal

- **Frontend:** React 19, Vite, Tailwind CSS v4, OGL (WebGL Shaders), Lucide Icons
- **Backend & AI:** Python, PyTorch, Scikit-Learn, Hugging Face, Node.js, C/C++
- **Databases:** PostgreSQL, MongoDB, SQL
- **DevOps:** Docker, Git, Linux, Cisco Packet Tracer
